# AI 产品经理 · 互动课堂

从用户研究（URX）转向 AI 产品经理的互动式学习网站。10 个模块、48 节课，覆盖大模型基础与 Agent 机制、模型选型与推理经济学、Prompt 系统化、评测体系、PRD 撰写、Roadmap 与指标、商业化与风险、作品集与面试，最后是一场 20 题 / 30 分钟的模拟面试。

## 三种练习

| 类型 | 说明 |
|---|---|
| 🧠 案例判断题 | 给你一个真实的决策场景，像产品经理一样做判断 |
| ✍️ 写作练习 | 真的写 PRD / 指标方案 / Prompt 调优记录，带自查清单与范文对照，草稿自动存在浏览器本地 |
| 🧮 量化练习 | 成本、A/B 样本量、Cohen's kappa 等，在网页里用真实 Python（Pyodide）算一遍 |

## 打开方式

- **在线**：https://jingyi22.github.io/ai-pm-course/
- **本地**：直接双击 `index.html`，或在本目录起一个静态服务器：
  ```bash
  npx serve .
  ```

首次打开需要联网加载 Python 运行环境（Pyodide），约 10~30 秒；之后走浏览器缓存。讲解与写作练习不依赖这个环境，可以先看。

## 进度与数据

- 学习进度（完成状态、XP、模块解锁、测验分数）存在浏览器 `localStorage`，关掉页面不丢。
- 写作草稿存在单独的本机键里。
- 课程里所有价格表、样本数据、公司场景均为**人工构造的示例**，不是任何真实公司的数据。
